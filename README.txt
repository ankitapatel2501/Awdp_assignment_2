MITTI & MAKERS - HANDMADE PRODUCTS E-COMMERCE PROJECT

Requirements:
- XAMPP / WAMP
- Apache
- MySQL
- PHP 7.4+ recommended

INSTALLATION:
1. Copy the Mitti_Makers_Ecommerce folder into:
   C:\xampp\htdocs\

2. Start Apache and MySQL from XAMPP.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin

4. Import:
   database/ecommerce.sql

5. Open:
   http://localhost/Mitti_Makers_Ecommerce/

ADMIN LOGIN:
Admin URL:
http://localhost/Mitti_Makers_Ecommerce/admin/login.php

Admin ID:
admin

Password:
admin123

IMPORTANT:
If your MySQL username/password is different, edit:
config/db.php
